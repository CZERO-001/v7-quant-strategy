# V7 盘中均线突破组合策略（2026 全量回测）

## 策略概述

V7 是从 V3（R0-R6）逐步演化而来的 12 层组合策略：
每天最多 1 条信号，按层优先级选股，层内取「突破时涨幅最高」，次日收盘卖出。

## 严格无未来函数

- 所有条件字段为 T 时刻（盘中实时）或 T-1 收盘（日线衍生）
- T+1 收益仅用于评估，不参与信号判断
- 抽查 3 条信号：买入价/突破涨幅/T+1 复算差异 <0.01pp

## 重要边界

- 2022/2023 的量能口径与 2026 有 30-40% 偏差（q.parquet 聚合 vs 1min parquet）
- 12 层顺序优化不能按 2026 单年做（会过拟合，主1 被踢到后面导致 2022/2023 崩）
- 2026 年的 129.35 万是理论复利，实盘应打折
